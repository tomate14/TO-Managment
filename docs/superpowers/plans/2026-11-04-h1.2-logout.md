# H1.2 Logout — plan

**Historia:** Como usuario quiero cerrar sesión para que nadie use mi cuenta en el dispositivo. Al cerrar sesión se borra el token del cliente y se vuelve al login.
**Mockups:** `docs/mockups/h1.2-logout/mobile-menu-mas.png` (fuente `docs/mockups/source/app/M-More.dc.html`), y el pie de `SideNav.dc.html` para escritorio.

## Decisiones
- **Solo frontend.** El JWT es stateless; el backend no cambia (no hay tabla nueva, `supabase/init/*` sin cambios).
- `AuthService.logout()` borra la sesión y navega a `/login` sin aviso (`SessionEndReason` suma `'logout'`).
- **Celular:** la tab bar suma la pestaña "Más" → ruta `/mas` (`MorePage`), con la tarjeta del usuario (iniciales, nombre, email, rol) y la sección "Mi cuenta" con "Cerrar sesión".
  - "Administración" (Usuarios, Catálogos) y "Cambiar contraseña" se agregan con H1.4, H2 y H1.5, para no dejar links muertos.
- **Escritorio:** el pie de la side nav suma el botón "Cerrar sesión" debajo de la tarjeta del usuario.
- **Verificación:** por pedido del usuario se escriben los tests, pero solo se verifica que backend y frontend compilen.

## Tareas
1. `AuthService.logout()` + test en `auth.service.spec.ts`.
2. `MorePage` (`features/more/`) + spec + ruta `/mas`.
3. Tab bar con "Más" (ítem propio de la tab bar, no de `NAV_ITEMS`) y side nav con "Cerrar sesión"; actualizar `shell.spec.ts`.
4. Compilar backend (`mvnw -B test-compile` en contenedor Java 21) y frontend (`ng build` + `tsc -p tsconfig.spec.json`).
