# H1.1 Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- La terapeuta ingresa con email y contraseña y recibe un JWT.
- Ve las pantallas de login de los mockups: normal, credenciales inválidas y sesión vencida, en mobile y escritorio.
- Al entrar llega a un shell de navegación vacío (barra inferior en mobile, menú lateral en escritorio).
- Con el token vencido vuelve al login con el aviso "Tu sesión venció".

**Architecture:**
- **Backend:**
  - Agrega Spring Security stateless. Un `JwtAuthenticationFilter` valida el token.
  - `POST /api/auth/login` es público y `GET /api/auth/me` está protegido.
  - Los usuarios viven en la tabla `app_user` (migración Flyway V2).
  - El JWT queda aislado detrás de la interfaz `TokenProvider` (patrón Adapter).
  - Todo error de seguridad (sin token, token vencido o inválido, acceso denegado) responde con el `ErrorResponse` uniforme.
- **Frontend:**
  - `AuthService`, un interceptor que agrega el token y maneja los 401, y guards.
  - La página de login sigue los mockups. El shell tiene `SideNav` y `TabBar`, con secciones vacías.

**Tech Stack:**
- Backend: Spring Boot 3.5.6, Spring Security 6, jjwt 0.12.6, BCrypt, Flyway, JUnit 5, Testcontainers.
- Frontend: Angular 21 (standalone, signals, formularios reactivos) y Vitest.

## Global Constraints

- **`.env` es la única fuente de verdad.** Prohibido hardcodear credenciales, puertos, hosts, URLs o nombres de volúmenes en código, `application.yml`, Dockerfiles o `docker-compose.yml`. En esta historia se usan solo variables que ya existen: `JWT_SECRET`, `JWT_EXPIRATION_MS` y `CORS_ALLOWED_ORIGINS`.
- **Imports y constantes en Java:**
  - Prohibido `import *`, también en `import static`.
  - Sin constantes sueltas: los valores fijos del dominio van en `enum`. Las excepciones aceptadas son el `Logger` estándar, los literales de rutas dentro de anotaciones de Spring (`@RequestMapping("/api/auth")`, que exigen constantes de compilación) y los mensajes de validación dentro de anotaciones `jakarta.validation`.
- **Servicios = interfaz + implementación** (`AuthService` / `AuthServiceImpl`). Los controllers dependen solo de la interfaz. Inyección por constructor.
- **Excepciones:** lanzar solo subclases de `ApplicationException`, con un código de `ErrorCode`. No usar `ResponseStatusException`. Al cliente nunca le llega un stack trace ni un mensaje interno.
- **Datos sensibles:** nunca se loguean contraseñas, tokens ni datos personales.
- **Idioma:** UI en español; código, identificadores, commits y nombres de archivos en inglés.
- **Frontend:**
  - Standalone components, rutas con lazy loading, formularios reactivos.
  - Mobile-first: estilos base para celular y media queries hacia arriba. El breakpoint de escritorio es `min-width: 1024px`.
  - Inputs con `font-size: 16px` y objetivos táctiles de 44 px o más.

```java
package com.tomanagement.user.entity;

import java.util.Locale;

/**
 * Single rule for comparing emails: trimmed and lower-cased, so lookups and uniqueness ignore case and spaces.
 */
public final class EmailNormalizer {

    private EmailNormalizer() {
    }

    public static String normalize(String raw) {
        return raw == null ? null : raw.trim().toLowerCase(Locale.ROOT);
    }
}
```

```java
package com.tomanagement.user.entity;

import java.time.Instant;
import java.util.Objects;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.EnumType;
import jakarta.persistence.Enumerated;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

/**
 * A person who can sign in. Built with the Builder pattern; the email is always stored normalized.
 */
@Entity
@Table(name = "app_user")
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 254)
    private String email;

    @Column(name = "password_hash", nullable = false, length = 100)
    private String passwordHash;

    @Column(name = "full_name", nullable = false, length = 120)
    private String fullName;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 20)
    private Role role;

    @Column(nullable = false)
    private boolean active;

    @Column(name = "created_at", nullable = false)
    private Instant createdAt;

    protected User() {
        // Required by JPA.
    }

    private User(Builder builder) {
        this.email = EmailNormalizer.normalize(Objects.requireNonNull(builder.email, "email is required"));
        this.passwordHash = Objects.requireNonNull(builder.passwordHash, "passwordHash is required");
        this.fullName = Objects.requireNonNull(builder.fullName, "fullName is required");
        this.role = Objects.requireNonNull(builder.role, "role is required");
        this.active = builder.active;
        this.createdAt = Objects.requireNonNull(builder.createdAt, "createdAt is required");
    }

    public static Builder builder() {
        return new Builder();
    }

    public Long getId() {
        return id;
    }

    public String getEmail() {
        return email;
    }

    public String getPasswordHash() {
        return passwordHash;
    }

    public String getFullName() {
        return fullName;
    }

    public Role getRole() {
        return role;
    }

    public boolean isActive() {
        return active;
    }

    public Instant getCreatedAt() {
        return createdAt;
    }

    public static final class Builder {

        private String email;
        private String passwordHash;
        private String fullName;
        private Role role;
        private boolean active = true;
        private Instant createdAt;

        private Builder() {
        }

        public Builder email(String email) {
            this.email = email;
            return this;
        }

        public Builder passwordHash(String passwordHash) {
            this.passwordHash = passwordHash;
            return this;
        }

        public Builder fullName(String fullName) {
            this.fullName = fullName;
            return this;
        }

        public Builder role(Role role) {
            this.role = role;
            return this;
        }

        public Builder active(boolean active) {
            this.active = active;
            return this;
        }

        public Builder createdAt(Instant createdAt) {
            this.createdAt = createdAt;
            return this;
        }

        public User build() {
            return new User(this);
        }
    }
}
```

```java
package com.tomanagement.auth.security;

import java.nio.charset.StandardCharsets;
import java.time.Clock;
import java.time.Instant;
import java.util.Date;

import javax.crypto.SecretKey;

import com.tomanagement.auth.config.JwtProperties;
import com.tomanagement.common.exception.AuthenticationFailedException;
import com.tomanagement.common.exception.ErrorCode;
import com.tomanagement.user.entity.Role;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.ExpiredJwtException;
import io.jsonwebtoken.JwtException;
import io.jsonwebtoken.JwtParser;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;

import org.springframework.stereotype.Component;

/**
 * Adapter from the jjwt library to TokenProvider. Signs with HMAC-SHA using JWT_SECRET; time comes from the injected
 * Clock so expiry is testable.
 */
@Component
public class JwtTokenProvider implements TokenProvider {

    private final SecretKey key;
    private final long expirationMs;
    private final Clock clock;
    private final JwtParser parser;

    public JwtTokenProvider(JwtProperties properties, Clock clock) {
        this.key = Keys.hmacShaKeyFor(properties.secret().getBytes(StandardCharsets.UTF_8));
        this.expirationMs = properties.expirationMs();
        this.clock = clock;
        this.parser = Jwts.parser()
                .verifyWith(key)
                .clock(() -> Date.from(clock.instant()))
                .build();
    }

    @Override
    public IssuedToken issue(AuthenticatedUser user) {
        Instant issuedAt = clock.instant();
        Instant expiresAt = issuedAt.plusMillis(expirationMs);
        String value = Jwts.builder()
                .subject(String.valueOf(user.id()))
                .claim(TokenClaim.EMAIL.getClaimName(), user.email())
                .claim(TokenClaim.FULL_NAME.getClaimName(), user.fullName())
                .claim(TokenClaim.ROLE.getClaimName(), user.role().name())
                .issuedAt(Date.from(issuedAt))
                .expiration(Date.from(expiresAt))
                .signWith(key)
                .compact();
        return new IssuedToken(value, expiresAt);
    }

    @Override
    public AuthenticatedUser parse(String token) {
        try {
            Claims claims = parser.parseSignedClaims(token).getPayload();
            return new AuthenticatedUser(
                    Long.valueOf(claims.getSubject()),
                    claims.get(TokenClaim.EMAIL.getClaimName(), String.class),
                    claims.get(TokenClaim.FULL_NAME.getClaimName(), String.class),
                    Role.valueOf(claims.get(TokenClaim.ROLE.getClaimName(), String.class)));
        } catch (ExpiredJwtException expired) {
            throw new AuthenticationFailedException(ErrorCode.TOKEN_EXPIRED);
        } catch (JwtException | IllegalArgumentException invalid) {
            throw new AuthenticationFailedException(ErrorCode.AUTHENTICATION_REQUIRED);
        }
    }
}
```

```java
 * Extracts the token from an "Authorization: Bearer <token>" header value.

public enum BearerToken {

    PREFIX("Bearer ");

    private final String value;

    BearerToken(String value) {
        this.value = value;

    public static Optional<String> extract(String authorizationHeader) {
        if (authorizationHeader == null || !authorizationHeader.startsWith(PREFIX.value)) {
```

```java
 * Not a Spring bean on purpose: SecurityConfig adds it to the chain, so it is not registered twice as a servlet filter.
 */
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private static final String ROLE_PREFIX = "ROLE_";

    private final TokenProvider tokenProvider;

    public JwtAuthenticationFilter(TokenProvider tokenProvider) {
        this.tokenProvider = tokenProvider;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        BearerToken.extract(request.getHeader(HttpHeaders.AUTHORIZATION)).ifPresent(token -> authenticate(request, token));
        chain.doFilter(request, response);
    }

    private void authenticate(HttpServletRequest request, String token) {
        try {
            AuthenticatedUser user = tokenProvider.parse(token);
            UsernamePasswordAuthenticationToken authentication = new UsernamePasswordAuthenticationToken(
                    user, null, List.of(new SimpleGrantedAuthority(ROLE_PREFIX + user.role().name())));
            SecurityContextHolder.getContext().setAuthentication(authentication);
        } catch (AuthenticationFailedException failure) {
            request.setAttribute(SecurityRequestAttribute.AUTHENTICATION_ERROR_CODE.key(), failure.getErrorCode());
        }
    }
}
```

`ROLE_PREFIX` es la convención fija de Spring Security (`hasRole`), no un valor del dominio. Si el revisor lo objeta, moverlo a un enum `AuthorityPrefix`.

```java
package com.tomanagement.auth.service;

import java.util.Optional;
import java.util.UUID;

import com.tomanagement.auth.dto.LoginRequest;
import com.tomanagement.auth.dto.LoginResponse;
import com.tomanagement.auth.dto.UserSummary;
import com.tomanagement.auth.security.AuthenticatedUser;
import com.tomanagement.auth.security.IssuedToken;
import com.tomanagement.auth.security.TokenProvider;
import com.tomanagement.common.exception.AuthenticationFailedException;
import com.tomanagement.common.exception.ErrorCode;
import com.tomanagement.user.entity.EmailNormalizer;
import com.tomanagement.user.entity.User;
import com.tomanagement.user.repository.UserRepository;

import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class AuthServiceImpl implements AuthService {

    private final UserRepository userRepository;
    private final PasswordEncoder passwordEncoder;
    private final TokenProvider tokenProvider;
    /** Hash compared when the email is unknown, so response time does not reveal which accounts exist. */
    private final String unknownUserHash;

    public AuthServiceImpl(UserRepository userRepository, PasswordEncoder passwordEncoder,
            TokenProvider tokenProvider) {
        this.userRepository = userRepository;
        this.passwordEncoder = passwordEncoder;
        this.tokenProvider = tokenProvider;
        this.unknownUserHash = passwordEncoder.encode(UUID.randomUUID().toString());
    }

    @Override
    @Transactional(readOnly = true)
    public LoginResponse login(LoginRequest request) {
        Optional<User> candidate = userRepository.findByEmail(EmailNormalizer.normalize(request.email()));
        String hash = candidate.map(User::getPasswordHash).orElse(unknownUserHash);
        boolean passwordMatches = passwordEncoder.matches(request.password(), hash);

        User user = candidate
                .filter(found -> passwordMatches && found.isActive())
                .orElseThrow(AuthenticationFailedException::new);

        IssuedToken token = tokenProvider.issue(
                new AuthenticatedUser(user.getId(), user.getEmail(), user.getFullName(), user.getRole()));
        return new LoginResponse(token.value(), token.expiresAt(), UserSummary.from(user));
    }

    @Override
    @Transactional(readOnly = true)
    public UserSummary currentUser(Long userId) {
        return userRepository.findById(userId)
                .filter(User::isActive)
                .map(UserSummary::from)
                .orElseThrow(() -> new AuthenticationFailedException(ErrorCode.AUTHENTICATION_REQUIRED));
    }
}
```

```ts
import { isJwtExpired } from './jwt-expiry';

function jwtWithExp(expSeconds: number): string {
  const payload = btoa(JSON.stringify({ sub: '1', exp: expSeconds })).replace(/=+$/, '');
  return `header.${payload}.signature`;
}

describe('isJwtExpired', () => {
  const now = new Date('2026-11-04T12:00:00Z');

  it('returns false before exp', () => {
    expect(isJwtExpired(jwtWithExp(now.getTime() / 1000 + 60), now)).toBe(false);
  });

  it('returns true at or after exp', () => {
    expect(isJwtExpired(jwtWithExp(now.getTime() / 1000), now)).toBe(true);
  });

  it('treats malformed tokens as expired', () => {
    expect(isJwtExpired('not-a-jwt', now)).toBe(true);
    expect(isJwtExpired('a.%%%.c', now)).toBe(true);
  });
```

```ts
/** True when the token's exp claim is not in the future. Unreadable tokens count as expired. */
export function isJwtExpired(token: string, now: Date = new Date()): boolean {
  try {
    const payload = token.split('.')[1];
    const json = atob(payload.replace(/-/g, '+').replace(/_/g, '/'));
    const exp = (JSON.parse(json) as { exp?: unknown }).exp;
    return typeof exp !== 'number' || exp * 1000 <= now.getTime();
  } catch {
    return true;
  }
}
```

```ts
import { Injectable } from '@angular/core';
import { UserSummary } from './auth.models';

export interface StoredSession {
  token: string;
  user: UserSummary;
}

const STORAGE_KEY = 'to-management.session';

/** Persists the session (token + user, never the password). Storage can be unavailable: failures are ignored. */
@Injectable({ providedIn: 'root' })
export class SessionStore {
  load(): StoredSession | null {
    try {
      const raw = localStorage.getItem(STORAGE_KEY);
      return raw ? (JSON.parse(raw) as StoredSession) : null;
    } catch {
      return null;
    }
  }

  save(session: StoredSession): void {
    try {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(session));
    } catch {
      /* private mode / blocked storage: session lives only in memory */
    }
  }

  clear(): void {
    try {
      localStorage.removeItem(STORAGE_KEY);
    } catch {
      /* ignore */
    }
  }
}
```

```ts
import { Injectable, computed, inject, signal } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Router } from '@angular/router';
import { Observable, map, tap } from 'rxjs';
import { LoginResponse, SESSION_EXPIRED_QUERY, SessionEndReason, UserSummary } from './auth.models';
import { SessionStore, StoredSession } from './session-store';
import { isJwtExpired } from './jwt-expiry';

export const LOGIN_URL = '/api/auth/login';
const ME_URL = '/api/auth/me';

@Injectable({ providedIn: 'root' })
export class AuthService {
  private readonly http = inject(HttpClient);
  private readonly router = inject(Router);
  private readonly store = inject(SessionStore);
  private readonly session = signal<StoredSession | null>(this.store.load());

  readonly currentUser = computed<UserSummary | null>(() => this.session()?.user ?? null);

  token(): string | null {
    return this.session()?.token ?? null;
  }

  hasValidSession(): boolean {
    const token = this.token();
    return token !== null && !isJwtExpired(token);
  }

  hasExpiredSession(): boolean {
    const token = this.token();
    return token !== null && isJwtExpired(token);
  }

  login(email: string, password: string): Observable<UserSummary> {
    return this.http.post<LoginResponse>(LOGIN_URL, { email, password }).pipe(
      tap((response) => this.setSession({ token: response.token, user: response.user })),
      map((response) => response.user),
    );
  }

  refreshCurrentUser(): void {
    this.http.get<UserSummary>(ME_URL).subscribe({
      next: (user) => {
        const current = this.session();
        if (current) {
          this.setSession({ ...current, user });
        }
      },
      error: () => undefined, // 401s are handled by the interceptor
    });
  }

  clearSession(): void {
    this.store.clear();
    this.session.set(null);
  }

  endSession(reason: SessionEndReason): void {
    this.clearSession();
    void this.router.navigate(['/login'], reason === 'expired' ? { queryParams: SESSION_EXPIRED_QUERY } : {});
  }

  private setSession(session: StoredSession): void {
    this.store.save(session);
    this.session.set(session);
  }
}
```

```ts
import { HttpErrorResponse, HttpInterceptorFn } from '@angular/common/http';
import { inject } from '@angular/core';
import { catchError, throwError } from 'rxjs';
import { AuthService, LOGIN_URL } from './auth.service';
import { apiErrorCode } from '../api/api-error';

const API_PREFIX = '/api/';

/** Adds the bearer token to API calls and ends the session on 401 (expired → login with notice). */
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const auth = inject(AuthService);
  const token = auth.token();
  const isLogin = req.url === LOGIN_URL;
  const sendsToken = token !== null && req.url.startsWith(API_PREFIX) && !isLogin;
  const request = sendsToken ? req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }) : req;

  return next(request).pipe(
    catchError((error: unknown) => {
      if (sendsToken && error instanceof HttpErrorResponse && error.status === 401) {
        auth.endSession(apiErrorCode(error) === 'TOKEN_EXPIRED' ? 'expired' : 'invalid');
      }
      return throwError(() => error);
    }),
  );
};
```

```ts
import { inject } from '@angular/core';
import { CanActivateFn, Router } from '@angular/router';
import { AuthService } from './auth.service';
import { SESSION_EXPIRED_QUERY } from './auth.models';

export const authGuard: CanActivateFn = () => {
  const auth = inject(AuthService);
  const router = inject(Router);
  if (auth.hasValidSession()) {
    return true;

  if (auth.hasExpiredSession()) {
    auth.clearSession();
    return router.createUrlTree(['/login'], { queryParams: SESSION_EXPIRED_QUERY });

  return router.createUrlTree(['/login']);
```

```ts
import { Component, ElementRef, inject, signal, viewChild } from '@angular/core';
import { NonNullableFormBuilder, ReactiveFormsModule, Validators } from '@angular/forms';
import { ActivatedRoute, Router } from '@angular/router';
import { HttpErrorResponse } from '@angular/common/http';
import { AuthService } from '../../../core/auth/auth.service';
import { SESSION_EXPIRED_QUERY } from '../../../core/auth/auth.models';
import { apiErrorCode } from '../../../core/api/api-error';
import { LoginHero } from '../login-hero/login-hero';

type LoginErrorKind = 'credentials' | 'incomplete' | 'emailFormat' | 'connection';

interface Banner {
  title: string;
  message: string;
}

const ERROR_BANNERS: Record<LoginErrorKind, Banner> = {
  credentials: { title: 'Email o contraseña incorrectos', message: 'Revisá los datos e intentá de nuevo.' },
  incomplete: { title: 'Completá tu email y contraseña', message: 'Necesitamos los dos datos para ingresar.' },
  emailFormat: { title: 'Revisá el formato del email', message: 'Tiene que ser como nombre@consultorio.com.' },
  connection: { title: 'No pudimos conectar con el servidor', message: 'Intentá de nuevo en unos minutos.' },
};

const HOME_URL = '/pacientes';

@Component({
  selector: 'app-login-page',
  imports: [ReactiveFormsModule, LoginHero],
  templateUrl: './login-page.html',
  styleUrl: './login-page.scss',
})
export class LoginPage {
  private readonly auth = inject(AuthService);
  private readonly router = inject(Router);
  private readonly formBuilder = inject(NonNullableFormBuilder);
  private readonly errorBanner = viewChild<ElementRef<HTMLElement>>('errorBanner');

  protected readonly form = this.formBuilder.group({
    email: ['', [Validators.required, Validators.email]],
    password: ['', [Validators.required]],
  });

  protected readonly loading = signal(false);
  protected readonly showPassword = signal(false);
  protected readonly error = signal<LoginErrorKind | null>(null);
  protected readonly sessionExpired = signal(
    inject(ActivatedRoute).snapshot.queryParamMap.get('sesion') === SESSION_EXPIRED_QUERY.sesion,
  );

  constructor() {
    this.form.valueChanges.subscribe(() => {
      if (!this.loading()) {
        this.error.set(null);
      }
    });
  }

  protected banner(kind: LoginErrorKind): Banner {
    return ERROR_BANNERS[kind];
  }

  protected isInvalid(field: 'email' | 'password'): boolean {
    const kind = this.error();
    if (kind === 'credentials') {
      return true;
    }
    if (kind === 'incomplete') {
      return this.form.controls[field].hasError('required');
    }
    return kind === 'emailFormat' && field === 'email';
  }

  protected togglePassword(): void {
    this.showPassword.update((shown) => !shown);
  }

  protected submit(): void {
    if (this.loading()) {
      return;
    }
    this.sessionExpired.set(false);
    const { email, password } = this.form.getRawValue();
    if (!email.trim() || !password) {
      this.fail('incomplete');
      return;
    }
    if (this.form.controls.email.hasError('email')) {
      this.fail('emailFormat');
      return;
    }
    this.loading.set(true);
    this.auth.login(email.trim(), password).subscribe({
      next: () => {
        this.loading.set(false);
        void this.router.navigateByUrl(HOME_URL);
      },
      error: (err: unknown) => {
        this.loading.set(false);
        this.fail(this.classify(err));
      },
    });
  }

  private classify(err: unknown): LoginErrorKind {
    if (err instanceof HttpErrorResponse && err.status === 401) {
      return 'credentials';
    }
    if (err instanceof HttpErrorResponse && err.status === 400 && apiErrorCode(err) === 'VALIDATION_ERROR') {
      return 'emailFormat';
    }
    return 'connection';
  }

  private fail(kind: LoginErrorKind): void {
    this.error.set(kind);
    queueMicrotask(() => this.errorBanner()?.nativeElement.focus());
  }
}
```

```ts
import { Role } from '../core/auth/auth.models';

export function userInitials(fullName: string): string {
  return fullName
    .trim()
    .split(/\s+/)
    .filter(Boolean)
    .slice(0, 2)
    .map((word) => word[0].toUpperCase())
    .join('');
}
```
